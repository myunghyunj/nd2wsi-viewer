# Example acquisition data

The `testdata-v1` release carries two Nikon ECLIPSE Ti2 fluorescence
acquisitions provided by the repository author for testing and
demonstration.

| file | content | size |
|---|---|---|
| example_cell.nd2 | cultured cells, 3 channels (CY3, FITC, DAPI), 2247 x 2185 px uint16, 0.66 um/px | 28 MB |
| example_tissue.nd2 | tissue section, 2 channels (CY5, DAPI), 3650 x 3406 px uint16, 0.66 um/px | 47 MB |

Both files were checked for embedded personal information (operator names,
machine paths, sample identifiers) before publishing and carry none.

They are released under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/):
use them for any purpose, no attribution required.
