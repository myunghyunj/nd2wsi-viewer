# nd2wsi-viewer v2.1 RC1

macOS / Apple silicon release candidate. The app keeps its original name:
**nd2wsi-viewer**. This is a prerelease, not a replacement for the stable feed.

## Changes

- Compatible cached uint16 fluorescence ND2 slides (1–8 channels, non-plate)
  display directly in an AppKit/Metal viewport on supported Apple silicon.
- Native pan, zoom, channel visibility, window, gamma and color LUT controls.
  Resident raw tiles are reused when display settings change: no extra source
  reads, CPU RGB/JPEG generation or display readback for those changes.
- Unsupported slides and hardware use the standard viewer. Open in Standard
  Viewer retains access to annotations, measurements, export and plate workflows.
- Independent windows/processes with isolated sessions; closing one does not
  close another. Native controls use the macOS system font (SF Pro).
- Update downloads are selected by OS, CPU and stable/RC channel. This RC ships
  only a macOS arm64 DMG. Windows remains at v2.0.0; no Windows binary update is
  published here. Existing stable installations do not automatically receive RC.

## Installation and updates

Download `nd2wsi-viewer-2.1.0rc1-macos-arm64.dmg` (macOS 12+, Apple silicon).
Close all viewer windows before replacing the app in Applications. This build
is ad-hoc signed, not Developer ID signed or notarized. In-app checks open a
compatible manual download; they do not replace a running multiwindow app.

## Validation and limits

Validated on an Apple M4 Pro Mac: native compilation, CPU/GPU pixel-reference
tests (maximum one 8-bit code-value difference), OS/CPU/channel routing and
window/session tests. The packaged app passes ND2 pixel-exact calibrated export
and JPEG/JPEG2000 SVS tile/ROI tests. The installed original-name app was used
to zoom, toggle a channel and change gamma on an isolated real two-channel ND2;
its separate standard window remained usable after closing the Metal window.

This is not disk-to-display zero-copy: input decode, transport and initial
shared-buffer staging still copy data. Native display has one fused viewport
pass and no production pixel readback. Nearest-neighbor raw sampling can look
different from the browser's filtered JPEG display. Native annotation editing,
plate playback, direct mmap sharing and inference are not included. Missing
or unsupported caches use the standard viewer.

GPU capture was generated but not inspected in Xcode because the installed
Xcode GUI was incompatible with this macOS version. Hardware bandwidth and
power are unmeasured; no bandwidth, energy or full-viewer speedup is claimed.
No Windows hardware validation was performed for this macOS-only RC.
