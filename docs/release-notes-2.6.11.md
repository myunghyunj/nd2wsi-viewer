# nd2wsi-viewer 2.6.11 (SLACS-module)

This SLACS lab module release pairs the 2.6.11 viewer updates—AstroMapper multi-step resize ROI parity, aligned 32 MiB ROI TXT limits, multi-channel OME-TIFF and degraded-overview export fixes, and cache security/cross-OS hardening—with SLACS Stage Follow and translucent overlay fixes. Automatic public-viewer update checks are disabled on `SLACS-module` builds.

- **SLACS Stage Follow & translucent overlay.** With Stage Follow stationary, a duplicate position report no longer cancels a valid target input. Locked translucent overlays automatically refresh click-through interactive regions when panels or hints resize, release the single-overlay claim promptly if a hidden overlay closes before showing, roll back Stage Follow startup cleanly on initialization failure, and enforce safe gesture-capture cleanup.
- **AstroMapper multi-step resize import & ROI parity.** Accept 1-step and 2-step whole-slide downscaled JPG/PNG reference images with a dual-guard aspect tolerance (up to 2 px minor-axis drift within 0.5% relative difference) and clear dimension-bearing mismatch errors. Add UTF-16 BOM ROI text decoding, PNG reference parity in the translucent viewer, 4,096-character ROI notes, integer-snapped dragged ROI boxes, a 2,000-ROI guard, checkbox undo/help shortcuts, boundary-clamped AstroMapper exports, and aligned 32 MiB ROI TXT export/import limits for large multi-byte note lists.
- **Multi-channel OME-TIFF & degraded-overview export fixes.** Write standards-compliant multi-IFD OME-TIFF 2016-06 files for multi-channel non-RGB exports, guard ND2 exports clearly when only a degraded overview cache is present, and report pre-stream export failures visibly in the interface.
- **Cache security, lifecycle & cross-OS hardening.** Validate full Zarr v2 metadata and reject symlinks and directory junctions across read/write and directory stores, harden overwrite-conversion metadata validation and preserve `.replaced-*` backups whenever the final cache is missing, improve lockfile descriptor handling, make shading-correction generation recovery atomic, improve live-LUT display-loop and tile-gate reliability, and unify NFC/NFD lockfiles with extended Windows long-path (`\\?\`) support.
