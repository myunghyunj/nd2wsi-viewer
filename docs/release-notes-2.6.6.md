# nd2wsi-viewer 2.6.6

This maintenance release fixes Windows NSIS Setup installation and upgrade usability, declutters Astromapper ROI overlays by showing number bubbles only for the active highlighted ROI, corrects the Windows memory budget for 200+ MPx RGB JPEGs, and delivers a comprehensive security, stability, format-parsing, and UI hardening pass.

- **Windows Setup installer fixes (`-setup.exe`).** Keep the **Install** button active on the destination folder page (`MUI_DIRECTORYPAGE_VERIFYONLEAVE`) and verify path validity and 64-bit free disk space with explicit dialogs instead of silently disabling the button; eliminate the multi-thousand-call path-check stall on fresh installations; use register-passed Win32 `System::Call` arguments for paths with special characters; honor bundled WebView2 Fixed Version runtimes for offline installs; and support clean in-place upgrades over prior Setup installations while preserving user files.
- **Cleaner Astromapper ROI number bubbles.** When loading or working with Astromapper TXT regions, display the numbered label bubble only for the currently active (yellow-highlighted) ROI — switching dynamically as you click an ROI box or step with the Left/Right arrow keys — instead of stacking overlapping bubbles over dense fields.
- **Large RGB JPEG memory budget on Windows.** Compute preflight RAM estimates from each image's actual Pillow decode footprint (5 B/px for direct RGB JPEGs rather than 16 B/px across all modes, against 75% of live available physical memory on Windows/Linux) and translate Pillow `MemoryError` cleanly, so ~215+ MPx stitched JPEGs (~820 MiB decoded) open reliably on 8–16 GB Windows PCs instead of demanding >6.4 GiB of free RAM.
- **Security, format-bounds, concurrency, and UI hardening.** Remove arbitrary `-c` execution from packaged launchers (switching Windows installer self-checks to `--cli-self-check`), allowlist safe Zarr v2 codecs with a 64 MiB chunk cap, harden the loopback HTTP server gate (`Host`/`Origin`/CSP/`X-Frame-Options`/timeouts), add XML DTD rejection and header/decompression bounds across CZI/LIF/OME-TIFF/SVS and shading models, guard native Metal viewport callbacks and memory accounting, fix scene-picker dropdown clipping and floating-window z-order/clamping, propagate custom channel colors to translucent overlays and Astromap exports, and scope the third-party `limnd2` package index exclusively in `pyproject.toml`/`uv.lock`.

### Downloads

- macOS: Apple silicon, macOS 14 or later. The app is ad-hoc signed; Sparkle update metadata is signed. It is not Developer ID signed or notarized.
- Windows: x64 per-user NSIS Setup installer (`-setup.exe`, no administrator UAC prompt) and portable ZIP; also supports Windows 11 ARM64 through x64 emulation. For the portable ZIP, extract the whole archive and keep `_internal` beside the executable. WebView2 is required; the installer and executable are not Authenticode-signed.
- Corresponding LGPL SDPC decoder sources and checksums are included for both platforms.
