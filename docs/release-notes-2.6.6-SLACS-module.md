# 2.6.6_SLACS-module

This lab release includes the [2.6.6 viewer updates](release-notes-2.6.6.md) paired with the SLACS lab module.

- **Windows Setup installer fixes (`-setup.exe`) and offline bundled WebView2.** Keep the **Install** button active on the destination folder page (`MUI_DIRECTORYPAGE_VERIFYONLEAVE`) and validate path syntax and 64-bit free disk space with clear dialogs rather than silently disabling the button; eliminate the multi-thousand-call path-check stall on fresh installations; use register-passed Win32 `System::Call` arguments; honor the bundled Microsoft Edge WebView2 Fixed Version Runtime (`-DBUNDLED_WEBVIEW2=1`) during Setup so offline Windows 10/11 lab PCs install cleanly without attempting an Evergreen download; and support clean in-place upgrades over prior Setup installations while preserving user files.
- **Cleaner Astromapper ROI number bubbles.** Display numbered Astromapper ROI label bubbles only for the currently active (yellow-highlighted) ROI when clicking an ROI box or stepping with Left/Right arrow keys, keeping dense fields unobstructed.
- **Large RGB JPEG memory budget on Windows.** Estimate decode RAM from each image's actual Pillow footprint (`5 B/px` for direct RGB JPEGs against 75% of live available RAM on Windows/Linux) with clean `MemoryError` translation, allowing ~215+ MPx stitched JPEGs to open reliably on 8–16 GB Windows lab PCs.
- **Security, format-bounds, concurrency, and UI hardening.** Remove arbitrary `-c` execution from packaged launchers (switching Windows installer verification to `--cli-self-check`), allowlist safe Zarr v2 codecs with a 64 MiB chunk cap, harden the loopback HTTP server gate (`Host`/`Origin`/CSP/`X-Frame-Options`/timeouts), add XML DTD rejection and header/decompression bounds across CZI/LIF/OME-TIFF/SVS and shading models, guard native Metal viewport callbacks, fix scene-picker clipping and floating-window z-order/clamping, propagate custom channel colors to translucent overlays and Astromap exports, and scope the third-party `limnd2` package index exclusively in `pyproject.toml`/`uv.lock`.
- **Isolated macOS SLACS bundle and Windows portable + Setup packages.** The Apple silicon DMG (`nd2wsi-viewer-2.6.6_SLACS-module-macos-arm64.dmg`) installs `nd2wsi-viewer SLACS.app` (`com.nd2wsi.viewer.slacs`) alongside the public viewer with automatic public-viewer updates disabled (`updates_off: true`). Windows ships both the portable archive (`nd2wsi-viewer-2.6.6_SLACS-module-windows-x64.zip`) and the per-user NSIS Setup installer (`nd2wsi-viewer-2.6.6_SLACS-module-windows-x64-setup.exe`, no administrator UAC prompt), both bundling the Microsoft Edge WebView2 Fixed Version Runtime. Hardware stage follow and laser controls remain available on supported Windows SLACS setups.

The macOS app is ad-hoc signed, not Developer ID signed or notarized. Windows builds are not Authenticode-signed. Corresponding LGPL SDPC decoder sources and checksums accompany the release.
