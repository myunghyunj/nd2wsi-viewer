# v1.2.5 comparison controls

## Changes

- Per-selected-slide horizontal/vertical flips, left/right 90-degree rotation, transpose and reset. Reference and other members are unchanged; original data and annotation/ROI coordinates stay in source space.
- No orientation is inferred from the file extension. Orientation changes preserve the captured image center and use the existing manual alignment model, not automatic or deformable registration.
- ROI polygons follow rotated/reflected images correctly.
- Closing the comparison toolbox hides only the tools. Linked panes, transforms, pending requests and landmark edits remain active. The tab-bar sliders button reopens the tools; the tab-bar link button ends comparison.
- Toolbox space is released while hidden and does not obstruct slide toolbars while visible.

## Verification before packaging

- Full local suite: 347 passed, including real ND2 fixtures. Ruff, JavaScript syntax and whitespace checks passed.
- Read-only real SVS/ND2 browser checks exercised orientation, reset, selected-member isolation, source-space ROI, and linked zoom/pan with the tools hidden.
- Hiding/reopening tools during Align preserved the edit; explicit link-button comparison teardown remained functional.
- The real-data QA source fingerprints and existing cache sizes/mtimes were unchanged (517 cache files checked). Research annotations were isolated from QA writes.

## Release gates

Before publication, require exact-source-SHA CI and realdata success, packaged smoke (including ND2 ROI round-trip), deep strict code-signature verification, installed source matching, release-asset SHA-256 verification and Sparkle Ed25519 verification. Record publication verification in the appcast follow-up commit.

Physical finger-input behavior was not newly tested; native gesture implementation and sensitivity are unchanged from v1.2.4. The distribution remains Apple-silicon/ad-hoc signed, not Developer ID notarized.
