# nd2wsi-viewer 2.6.5

This release adds native OME-TIFF / TIFF / QPTIFF viewing and `2016-06` OME-XML TIFF ROI export, a toolbar **Series** picker across multi-series and multipoint acquisitions, channel color presets and soloing, 50-step annotation Undo/Redo, coordinated multi-tab concurrency and memory bounds, and a per-user Windows NSIS Setup installer alongside the portable ZIP.

- **Native OME-TIFF / TIFF / QPTIFF viewing, OME-XML ROI export, and scanner fixes.** Open pyramidal, tiled, and untiled `.ome.tif`, `.ome.tiff`, `.tif`, `.tiff`, and `.qptiff` slides and multi-plane stacks directly, export `2016-06` OME-XML `.tif` regions with physical pixel calibration and channel metadata, and preserve full `.tif` / `.ome.tif` / `.qptiff` round-trip annotation and LUT sidecars (including Nikon NIS-Elements `<InstrumentRef>` attributes, 24-bit RGB signed-integer channel colors, and multipoint IFD offsets). Zeiss ZEN `.czi` acquisitions with non-zero `StartC` or disabled tracks (`IsSelected="false"`) map active channels accurately.
- **Multi-series and multipoint scene picker (`#scene-picker`).** Switch heterogeneous series, scenes, and positions directly from the toolbar **Series** selector across Leica `.lif`, Zeiss `.czi`, multi-series `.ome.tif`, and non-plate multipoint Nikon `.nd2` (`XYPosLoop`) files, with per-series sidecar and LUT isolation.
- **Channels, UI, and workflow polish.** Click channel `.swatch` controls for color presets or metadata reset, `Option / Alt`-click channel toggles to solo a channel, use 50-step `⌘Z` / `⌘⇧Z` (`Ctrl+Z` / `Ctrl+Y`) annotation Undo/Redo and two-step Astromap **Clear all** with Undo, open the `?` Keyboard Shortcuts modal, access expanded `#shell-tools` toolbar controls, reopen **Recent** slides from the start screen (`boot.html`), persist theme and panel layout in `ui-settings.json`, and gate native **ND2** ROI export (`nd2Export`) to `uint8` / `uint16` non-raster slides.
- **Coordinated concurrency and memory bounds.** Bound multi-tab viewing and 5–20 GB scanner acquisitions with a 4-reader SQLite connection pool (`<= 32 MiB` cache per store), decoded chunk LRU and `jpeg8_encode` fast path, a RAM-bounded shared stack frame cache with single-flight plane deduplication, epoch-cancelled 1-worker Z-neighbor prefetch, lazy strip-streaming for `> 64 MiB` untiled TIFFs, a bounded 16-worker HTTP pool, and `server_bind` startup without reverse-DNS (`getfqdn`) delays.
- **Windows per-user NSIS Setup installer and CI signing hooks.** Ship a per-user Windows NSIS Setup executable (`nd2wsi-viewer-2.6.5-windows-x64-setup.exe`, installing under `%LOCALAPPDATA%\Programs\nd2wsi-viewer` with `HKCU` file associations and zero administrator UAC prompts) alongside the portable `.zip`, plus optional macOS Developer ID / `notarytool` / `stapler` and Windows SHA-256 Authenticode CI release hooks.

### Downloads

- macOS: Apple silicon, macOS 14 or later. The app is ad-hoc signed; Sparkle update metadata is signed. It is not Developer ID signed or notarized.
- Windows: x64 per-user NSIS Setup installer (`-setup.exe`, no administrator UAC prompt) and portable ZIP; also supports Windows 11 ARM64 through x64 emulation. For the portable ZIP, extract the whole archive and keep `_internal` beside the executable. WebView2 is required; the installer and executable are not Authenticode-signed.
- Corresponding LGPL SDPC decoder sources and checksums are included for both platforms.
