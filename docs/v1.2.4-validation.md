# v1.2.4 correctness candidate

## Changes

- User-facing plate operations require an explicit selected site. Grid channels and manual LUT remain global; histogram Auto, Pixel Inspector, annotations and ROI/export require focus. Only the hidden renderer can use a backing P0.
- Pixel and histogram requests capture source generation and T/P/Z, abort obsolete work, and reject stale success, failure and finalization. Annotation persistence captures its site owner across focus changes.
- Plate ROI is site-owned, labeled Full Field, retained across T/Z at that site, and cleared on site/grid changes. All-site export is explicitly unavailable.
- Autofocus applies only complete Z curves at the current T/P. Grid shows actual visible Z range and readiness; the method remains all raw channels averaged, not channel-selectable or confidence-calibrated.
- AF is accessible outside the timeline. Singleton positions open focused; Time/Z and grid keyboard accessibility preserve the existing View controls and shortcuts.
- Native gesture scope excludes non-plate UI. Physical and momentum phases retain one axis/target. Existing sensitivity and 100 ms idle threshold are unchanged. The undecided prefix within an eligible stage is still held; this patch does not claim to recover that vertical prefix.

## Checks completed before packaging

- Final full suite: 314 passed, no skips, including five real ND2 tests using temporary copies of the existing example acquisitions.
- Production annotation functions are exercised in a mocked request environment: grid/null issues zero P0 requests; A-to-B-to-A waits for saves, recovers failed in-memory snapshots instead of stale disk data, and clears the failure record after retry succeeds.
- Ruff lint, JavaScript syntax and whitespace checks pass. Repository-wide optional formatter checks report pre-existing formatting differences; no broad formatting rewrite was made.
- Browser UI on synthetic P256/T1/Z1: coordinate headers; absent axes; disabled grid Auto/Region with visible explanation; arrow navigation to the next cell; Enter focus; selected-site Full Field and preview.
- Browser UI on synthetic P4/T2/Z3: Time End key advances to T2; AF displays mixed Z range and 4/4 readiness; Hide Timeline preserves AF; R opens Region.
- Singleton browser QA found a CSS specificity collision showing All sites and the strip in focused P=1. The singleton rule now outranks the later focus rule; a regression contract guards that precedence.
- Singleton browser recheck confirms initial focus, visible Z/AF, no Timeline and no All sites/strip controls.
