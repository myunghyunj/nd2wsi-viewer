# 2.6.5_SLACS-module

This lab release includes the [2.6.5 viewer updates](release-notes-2.6.5.md) paired with the SLACS lab module.

- **Native OME-TIFF / TIFF / QPTIFF viewing, OME-XML ROI export, and scanner fixes.** Open pyramidal, tiled, and untiled `.ome.tif`, `.ome.tiff`, `.tif`, `.tiff`, and `.qptiff` slides and multi-plane stacks directly, export `2016-06` OME-XML `.tif` regions with physical pixel calibration and channel metadata, preserve full `.tif` / `.ome.tif` / `.qptiff` round-trip annotation and LUT sidecars, and map Zeiss ZEN `.czi` active channels accurately when `StartC` is non-zero or tracks are disabled.
- **Multi-series and multipoint scene picker (`#scene-picker`).** Switch heterogeneous series, scenes, and positions directly from the toolbar **Series** selector across Leica `.lif`, Zeiss `.czi`, multi-series `.ome.tif`, and non-plate multipoint Nikon `.nd2` (`XYPosLoop`) files, with per-series sidecar and LUT isolation.
- **Channels, UI, and concurrency bounds.** Use clickable channel `.swatch` color presets and `Option / Alt`-click channel soloing, 50-step `⌘Z` / `⌘⇧Z` (`Ctrl+Z` / `Ctrl+Y`) annotation Undo/Redo, two-step Astromap **Clear all** with Undo, the `?` Keyboard Shortcuts modal, start-screen **Recent** slides, persisted `ui-settings.json` layout, `uint8` / `uint16` `nd2Export` dtype gating, and bounded multi-tab SQLite / tile / stack-frame / Z-prefetch memory budgets without reverse-DNS (`getfqdn`) startup stalls.
- **SLACS translucent overlay, stage follow, and laser target parity across all formats.** Translucent overlay tracing, calibrated laser target aiming (`SLACS_ROI #N` shot tracking), per-format W/S and A/D stage-follow flip memory, and per-process JSONL session logging work consistently across OME-TIFF / TIFF / QPTIFF, ND2, CZI, LIF, SVS, and SDPC slides.
- **Isolated macOS SLACS bundle and Windows portable + Setup packages.** The Apple silicon DMG (`nd2wsi-viewer-2.6.5_SLACS-module-macos-arm64.dmg`) installs `nd2wsi-viewer SLACS.app` (`com.nd2wsi.viewer.slacs`) alongside the public viewer with automatic public-viewer updates disabled (`updates_off: true`). Windows ships both the portable archive (`nd2wsi-viewer-2.6.5_SLACS-module-windows-x64.zip`) and the per-user NSIS Setup installer (`nd2wsi-viewer-2.6.5_SLACS-module-windows-x64-setup.exe`, no administrator UAC prompt), both bundling the Microsoft Edge WebView2 Fixed Version Runtime. Hardware stage follow and laser controls remain available on supported Windows SLACS setups.

The macOS app is ad-hoc signed, not Developer ID signed or notarized. Windows builds are not Authenticode-signed. Corresponding LGPL SDPC decoder sources and checksums accompany the release.
